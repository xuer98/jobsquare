# Notes

Cross-cutting material that doesn't belong to any one problem.

- `complexity.md` — the table you should be able to recite: every structure's op costs.
- `patterns.md` — trigger phrase → pattern → template code. The recall index.
- `js-trivia.md` — event loop ordering, `this` binding, prototype chain, coercion, CORS,
  module systems. The stuff that gets asked between coding rounds.
- `behavioral.md` — 6–8 STAR stories, each reusable across "conflict", "failure",
  "ambiguity", "influence". Write them once, tag them by which question they answer.
- `questions-to-ask.md` — per-company, filled in the day before.
- `log.md` — dated mock-interview log: problem, time taken, outcome, what broke.

`log.md` is the one that actually changes your score. Everything else here is reference.
